# 07 — Убрать локальный сертификат подписи

Создан: 2026-10-01

## Цель

Перейти на настоящий Developer ID (см. ADR 011). Локальный сертификат остаётся режимом отладки и в репозиторий не попадает.

## Объём работ

- [x] Сертификат выбирается в `scripts/install-local.sh` из `.private/signing.env`, `--adhoc` — как релиз — 2026-10-04.
- [ ] Подписывать сборки Developer ID в `bundle.sh` / `make-dmg.sh`.

## Критерий готовности

Релизная сборка подписана Developer ID, права Nook (запись экрана, Accessibility) переживают обновление у пользователя.
