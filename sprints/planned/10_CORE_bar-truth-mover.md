# 10 — Правда — строка: чтение строки, зеркало и перенос по одной иконке

Создан: 2026-10-04

## Цель

Заменить «Применить» и реестр «как должно быть» моделью из ADR 020: Nook читает настоящий порядок
строки меню, хранит его в зеркале и переставляет иконки по одной на каждый бросок в редакторе.

## Исходное состояние

- Стабильная версия — тег `v0.3.2`: «Применить» с адресными переносами (ADR 019).
- В рабочей копии (не закоммичено) лежит эксперимент — бросок без «Применить»:
  `mover::move_one`, `stands_between`, `onTileDropped:` / `onTileMoved:` в контроллере, блокировка
  плиток в редакторе, кнопка «Применить» спрятана (`settings.rs`, TODO), проба `HARDCODE` в
  `move_next_to` (адресный перенос иконки под чёлкой). Из него берём идеи и куски, но не строим
  на нём: новый путь пишется отдельным модулем.
- Пробы чтения порядка: скрипт `orderprobe.swift` (печатает окно, Accessibility и Preferred Position
  по каждой иконке) — перенести в `scripts/` в начале спринта.

## Объём работ

### 1. Чтение строки
- [ ] Модуль чтения: по каждой иконке номер окна, имя окна, x окна, x из Accessibility, процесс
  приложения, Preferred Position; список слева направо (сортировка по x, знак не важен).
- [ ] Признак доверия: под чёлкой нет ни одной иконки и разделитель не узкий.
- [ ] Два уровня: дешёвый тик (только окна) и полное чтение (с Accessibility) по изменению, при старте,
  при открытии и закрытии раздела.
- [ ] Сопоставление окна и иконки приложения по ближайшему x с допуском; тайм-аут на приложение.
- [ ] Лог расхождений трёх источников — по нему выбрать основной.

### 2. Зеркало
- [ ] Список `[панель …] разделитель [основной ряд …]` по номерам окон.
- [ ] Сверка с чтением: доверенное — принять целиком; нет — видимые из строки, спрятанные из зеркала;
  новая спрятанная — в конец панели; пропавшая — убрать.
- [ ] Сохранение на диск по ключу «приложение + имя окна», загрузка при старте (уходит баг «после
  запуска всё в панели»).

### 3. Перенос
- [ ] Одна операция «перенести иконку к соседу или к разделителю» поверх адресного переноса ADR 019,
  проверка, что встала, запись в зеркало.
- [ ] Одна очередь на переносы и чтения.
- [ ] Неподвижная иконка: остальные встают вокруг неё той же операцией; пометка по ключу на сеанс.

### 4. Редактор и панель
- [ ] Редактор и панель рисуют зеркало.
- [ ] Бросок плитки → одна операция «перенести»; пока идёт — плитки не берутся; не встала — плитка
  возвращается, рядом пояснение.
- [ ] Закрытие раздела: разделитель широкий → полное чтение → сверка.
- [ ] Автоматическое расположение (ADR 018) на той же модели.

### 5. Удаление старого пути
- [ ] Удалить «Применить» целиком: кнопку, цепочку таймеров, `arrange`/`arrange_all`, `push_into_notch`,
  `replace_divider` после переноса, `bar_matches`, заморозку реестра, тексты пояснений, которые
  больше не нужны.
- [ ] Закрыть пункты спринта 09, которые ушли вместе со старым путём.
- [ ] Обновить ADR 013, 019, 020 и README решений.

## Критерий готовности

- Бросок плитки в любой ряд — иконка в строке встаёт за ≈ 200 мс, курсор не виден.
- Иконка, спрятанная под чёлкой, переносится так же.
- Ручной Cmd+drag видимой иконки и иконка, которую приложение добавило само, видны в редакторе
  после ближайшего чтения.
- После перезапуска Nook ряды те же, что до него.
- Little Snitch: остальные иконки встают вокруг неё.
- Кода «Применить» в проекте нет.
