# 08 — Предупреждение, когда не хватает разрешений

Создан: 2026-10-03

## Цель

Без Accessibility «Применить» молча ничего не двигает, и непонятно почему. Nook должен сам показать, что разрешения нет.

## Объём работ

- [ ] Жёлтый значок ⚠ у раздела «Разрешения» в настройках, пока какого-то разрешения нет.
- [ ] Жёлтая строка с ⚠ над «Применить»: «Нет доступа Accessibility — иконки не переставить» и кнопка открыть настройки.
- [ ] Без Accessibility кнопка «Применить» неактивна.
- [ ] Подключить гибрид после обновления: `permissions::reset_stale_after_update` и `remember_if_granted` + строка «После обновления включите разрешения заново».

## Критерий готовности

Выключили Accessibility у Nook — в настройках видно жёлтое предупреждение, «Применить» неактивна. Включили — предупреждение пропало.
