# 08 — Предупреждение, когда не хватает разрешений

Создан: 2026-10-03 · Обновлён: 2026-10-04 («Применить» удалено, перенос идёт по броску)

## Цель

Без Accessibility бросок в редакторе молча ничего не двигает, и непонятно почему. Nook должен
сам показать, что разрешения нет.

## Объём работ

- [ ] Жёлтый значок ⚠ у раздела «Разрешения» в настройках, пока какого-то разрешения нет.
- [ ] Жёлтая строка с ⚠ над редактором: «Нет доступа Accessibility — иконки не переставить» и
  кнопка открыть настройки.
- [ ] Без Accessibility редактор не принимает броски.
- [x] Разрешения после обновления: кнопка сброса и подсказка «выдайте заново» (0.3.1).

## Критерий готовности

Выключили Accessibility у Nook — в настройках видно жёлтое предупреждение, редактор не
принимает броски. Включили — предупреждение пропало.
