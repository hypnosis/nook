# 05 CORE — Настройки, hotkey, автозапуск

Дата создания: 2026-06-05 · Обновлён: 2026-10-04

## Цель

Дать пользователю настройки: горячую клавишу для переключения скрытия и автозапуск при входе в систему.

## Объём работ

- [x] Окно настроек: «Основные», «Расположение», «Разрешения».
- [ ] Глобальный hotkey для toggle (скрыть/показать).
- [x] Автозапуск при логине через `SMAppService` (ADR 009).
- [x] Настройки и порядок панели переживают перезапуск.

## Критерий готовности

В окне настроек можно задать hotkey и включить автозапуск; hotkey переключает скрытие; после
перезагрузки приложение само запускается, настройки сохранены. Остался только hotkey.
