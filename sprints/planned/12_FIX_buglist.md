# 12 — Баглист

Создан: 2026-10-25 · Ветка `feat/notch-shroud`, тег `notch-shroud-stable`

## Цель

Собрать найденные баги в одном месте: замечания владельца и находки двух независимых ревизий
кода (Opus и Sonnet). Сначала баги, потом рефакторинг.

Пометки: «оба» — нашли оба ревьюера; «предп.» — по коду похоже, руками не проверено;
«ТД» — уже есть в `09_CORE_review-tech-debt.md`.

## Баги

### Высокая

- [x] **B1. Шторка закрывала меню приложения.** Длинное меню (Keynote) продолжается справа от
  чёлки, в полосе иконок панели; иконки под ним macOS прячет сама. Шторка лежала выше и
  закрывала названия меню. Починено: правый край меню активного приложения берётся через
  Accessibility; заходит в полосу — шторки нет. Проверяется при смене приложения, на каждом
  чтении и перед раскрытием. Проверено владельцем 2026-10-25.
- [ ] **B2. Отменённый перенос продолжает работать (оба).** После отмены сторожем поток всё равно
  вносит иконку в непереносимые до перезапуска, двигает курсор и стирает шаг нового переноса.
  Потом отчитывается и отдаёт мышь посреди нового переноса. `mover.rs` `move_one`/`restore`.
- [ ] **B3. Без права «Запись экрана» иконки панели видны.** Разделитель сужается по одной
  геометрии. Если снимок не получился (нет права, таймаут), шторки нет, а иконки панели стоят
  у чёлки на виду. Сужать только при готовой картинке. `bar.rs` `divider_length`.

### Средняя

- [ ] **B4. Снимок шторки на главном потоке, ожидание до 2 с (оба).** При раскрытии и сужении
  разделителя. Если ScreenCaptureKit тормозит, весь Nook стоит. `cover_now` → `shoot_now`.
- [ ] **B5. Чтения строки и снимки шторки не объединяются (оба).** На каждый запрос создаётся
  новый поток, а результат лежит в одной общей ячейке. Поздний поток затирает свежий
  результат, на старте возможно ложное «разделитель не прочитан». `bar.rs` `LATEST`, `shroud.rs`
  `PICTURE`. Частично: старое чтение больше не затирает свежее (`read_when_still`, сравнение
  `epoch`); поток на каждый запрос остаётся.
- [ ] **B6. Повторный заём `RefCell` при пересоздании элементов (оба, предп.).** Заём держится
  поверх вызовов AppKit. Если уведомление о сдвиге окна придёт синхронно, будет паника, а
  в release это `abort`. `controller.rs` `recreate_*`, `toggle`.
- [ ] **B7. Разделитель не создаётся, если строку свернули до конца размещения (оба, предп.).**
  Потом до перезапуска не работают панель, редактор и броски. `finish_placement_if_ready`.
- [ ] **B8. Экран и чёлка берутся с разных экранов (оба, частично ТД).** `screens[0]` против
  `mainScreen`. С окном настроек на внешнем мониторе чёлка = 0. Ширина спейсера при смене
  экранов не пересчитывается.
- [ ] **B9. Кэш Accessibility (оба, частично ТД A6/B).** На время нажатия элемент вынимается из
  кэша, и чтение запускает полный обход. Обход делает поток на каждый процесс. Кэш только
  растёт. Список непереносимых вечный.
- [x] **B10. Сторож порядка работает при свёрнутой строке.** Раз в 0,5 с полный список окон на
  главном потоке; ADR 022 обещает, что в свёрнутом виде Nook ничего не делает. Сделано в 0.4.8:
  сторож только при раскрытой строке.
- [ ] **B11. Снимки иконок панели каждую секунду вхолостую.** Даже когда ничего не менялось.
  Поздний снимок может затереть свежий. Возможно, держит индикатор записи экрана. Решено
  владельцем: раз в 1 с остаётся (часы и батарея должны быть свежими); открыто только затирание.
- [ ] **B12. Отброшенное стартовое чтение не перезапрашивается (предп.).** Строка остаётся
  раскрытой до ручного клика.

### Низкая

- [ ] **B13.** Переключатель «авто» во время переноса показывает не то состояние (оба).
- [x] **B14.** Клик по `<` при вердикте «ещё не знаю» ставит ⚠ и блокировку, а должен ждать.
  Сделано: `Unknown` и `Hidden` при сворачивании ждут.
- [ ] **B15.** Флаг «меню открыто» без защиты: при панике потока клики по копиям умирают навсегда.
- [ ] **B16.** Автозапуск из меню в dev-сборке регистрирует путь `target/debug`.
- [ ] **B17.** Номер окна −1 превращается в `u32::MAX` при приведении типа.
- [ ] **B18.** Ключ иконки — имя приложения: смена языка системы теряет порядок панели (предп.).
- [ ] **B19.** Тема читается сразу после уведомления и может быть ещё старой (предп.).
- [ ] **B20.** Вставка в редакторе паникует при позиции за концом ряда; защита только снаружи (предп.).
- [ ] **B21.** Повторный старт восстановления может оставить курсор скрытым (предп.).
- [x] **B22.** Цепочки таймеров сторожа переноса не гасятся, их может стать две. Сделано:
  у таймеров есть владелец (`timer.rs`), новый взвод сторожа переноса гасит прошлый.
- [ ] **B23.** Фильтр окон по слову «Clone» может отсеять чужую иконку (предп.).
- [ ] **B24.** Лог «переносов N» считает попытки, а не удачные переносы.
- [ ] **B25.** Монитор мыши автосворачивания без освобождения при забытом `stop`.
- [ ] **B27.** Окно, открытое нажатием позже 1,5 с, не считается подсветкой: следующий снимок
  шторки может её поймать (предп.).
- [ ] **B28.** Окно, открытое нажатием до перезапуска Nook, новый Nook не знает: стартовый
  снимок шторки ловит подсветку. Обход — закрыть окно.
- [ ] **B29.** Край меню приложения перед раскрытием читается через Accessibility на главном
  потоке (до 0,1 с на вызов); повисшее приложение задержит раскрытие.
- [x] **B31. Осечка переноса Nook переписывает порядок на диске.** Выход из авто: два переноса
  восстановления «не взялись по адресу», чтение увидело иконки в основном ряду, `layout::observe`
  сохранил это на диск — cmux, Ollama, AdGuard выпали из панели, следующий выход из авто
  восстанавливать уже нечего. Правило владельца: редактор (диск) — намерение, строка — факт;
  Nook приводит факт к намерению, своя осечка намерение не меняет, меняют только бросок в
  редакторе и Cmd+drag пользователя. Сделано: намерение меняется точечно, после своего
  переноса Nook сверяет строку с намерением, повторяет один раз, потом пишет в журнал.
  Открыто: причина самой осечки у чёлки (x=838) — в `mover`.
- [x] **B30.** Автосворачивание пропускается, если в момент срабатывания открыто меню копии, и
  таймер не взводится заново: после закрытия меню строка висит раскрытой, пока мышь не зайдёт в
  строку и не уйдёт. Сделано: при открытом меню таймер взводится заново.
- [ ] **B26.** FFI: картинка темы поверх буфера `Vec`, `Send` у снимка ScreenCaptureKit без
  обоснования, приватные CGS-вызовы без проверки результата (предп.).

## Рефакторинг (после багов)

- Шторка расходится с ADR 022 — переписать ADR (ТД A11).
- `controller.rs` — God-модуль: вынести запуск и размещение, сторож, шторку, переносы, сворачивание.
- Доставка в контроллер через общие ячейки и строковые селекторы → передача данных по значению.
- Копипаста: таймеры (8 мест), начало и конец переноса, поиск окна Nook по имени (6 мест), три
  копии «встать после левого соседа» в `layout.rs`, `UNPLACED_X` дважды.
- Деление на панель и основной ряд с разными допусками в `bar.rs`.
- `tuning.rs`: смешаны секунды и `Duration`, неточные имена (`ANCHOR_MAX_RETRIES`,
  `PANEL_CAPTURE_DELAY`), три допуска координат, магические числа вне файла.
- Настройки: хранилище и окно в одном модуле, `LAYOUT_PANE` согласуется вручную.
- Комментарии с историей и устаревшие шапки (ТД C).
- Тесты: нет тестов на контроллер, `mover::target_points`, `placement`.

## Критерий готовности

Каждый баг починен и проверен владельцем либо осознанно закрыт как принятый риск.
