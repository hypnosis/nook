# 11 — Раскладка по одной логике

Создан: 2026-10-05 · Завершён: 2026-10-05

## Цель

Переписать ядро раскладки под ADR 022 «Логика раскладки»: одно чтение строки, одна модель,
панель и редактор только показывают её решения.

## Почему

Починки раскладки создавали новые баги: решение «что в панели» принимали пять мест сразу,
а ADR 012–020 противоречили друг другу. Пример: узкий режим держал иконки панели в видимой
строке под шторкой, и AdGuard через 2 секунды появлялся в строке, оставаясь в панели.

## Сделано

- [x] Замер: имена окон иконок почти у всех `Item-0` — ключ на диске «приложение + номер
  иконки внутри приложения».
- [x] Документы: ADR 022 переписан в единственный документ о раскладке, ADR 012, 013, 015,
  016, 018, 020 помечены историей.
- [x] Модель (`layout.rs`) — чистая логика, сценарии 1–9 — автотесты. Чтение строки
  (`bar.rs`) — одно на всё приложение.
- [x] Контроллер: один таймер чтения, поколение строки вместо флагов, старые сверка,
  восстановление с диска, отложенный ручной порядок удалены.
- [x] Разделитель панели не сужается и не удаляется, ширина подстраивается после каждого
  чтения. Узкий режим и шторка удалены, копия нажимает иконку там, где она спрятана.
- [x] Панель рисует вид модели, картинки хранит по иконке: неудачный снимок иконку не убирает.
- [x] Авторежим: разделителя в строке нет. Выход из авто восстанавливает запомненную раскладку
  переносами чужих иконок; курсор спрятан всё время.
- [x] Шум у чёлки (перестановка ненарисованных иконок основного ряда) не считается событием.
- [x] Проверено владельцем: иконки панели не появляются в строке, авто ↔ ручной возвращает
  раскладку, поведение предсказуемое.

## Что выяснили

- Невидимый элемент строки macOS забывает так же, как удалённый: место разделителя знает Nook.
- Событие, адресованное собственному элементу Nook, показывает спрятанный курсор. Поэтому
  Nook никогда не переносит свой разделитель, только чужие иконки к нему.
- Восстановление: перенос ≈ 90 мс, всё ≈ 0,6 с.

## Перенесено в техдолг (спринт 09)

- Курсор при восстановлении после отказа от переноса разделителя — подтвердить руками.
- Поиск приложений иконок через Accessibility повторяется на каждом чтении, пока владелец
  спрятанной иконки не найден.
- На время восстановления разделитель узкий, иконки панели могут на миг мелькнуть.

## Критерий готовности

- `cargo test`: сценарии 1–9 зелёные. ✅
- Строка раскрыта, панель открыта — ни одна иконка панели не появляется в строке. ✅
- Авто включил и выключил — всё как было. ✅
- Cmd+drag в строке и новая иконка приложения видны в панели и редакторе, Nook их не
  возвращает. ✅ автотестами; руками — при следующем прогоне.
