# 10 — Правда — строка: реестр и перенос по одной иконке

Создан: 2026-10-04 · Завершён: 2026-10-04 (версии 0.4.0 и 0.4.1)

## Цель

Заменить «Применить» моделью из ADR 020: строка меню — реальный порядок, каждый бросок в
редакторе — один перенос одной иконки. Nook сам иконки не двигает.

## Модель, как она работает теперь

- **Основной ряд — порядок строки целиком**, вместе с иконками, которые macOS не нарисовала:
  в строке они всегда крайние слева. Поэтому видимая строка — правый хвост ряда в редакторе.
- **Панель** держит свой порядок в реестре (внутри панели бросок строку не трогает) и сохраняет
  его на диск по имени приложения.
- **Бросок** — один перенос к соседу по редактору, между рядами сосед — разделитель. После
  переноса реестр перечитывается из строки, и редактор показывает, куда иконка встала на деле.
- **Nook без действия пользователя ничего не двигает.**

- [x] Цепочка «Применить» удалена целиком: кнопка, таймеры, добивочные проходы, выталкивание
  в чёлку, пересоздание разделителя.
- [x] Один перенос на бросок; без проверки «встала» и отката плитки — правду показывает сверка.
- [x] Пока открыт раздел «Расположение», разделитель не сужается: строку не перестраивает
  посреди бросков.
- [x] Основной ряд сверяется со строкой целиком, спрятанные иконки тоже.
- [x] Точка отпускания у чёлки — сразу правее её края, не под ней.
- [x] Порядок панели переживает перезапуск Nook (ключ `panelOrder`, имена приложений).
- [x] Проверено владельцем: броски между рядами, внутри рядов, с камерой (ряд упирается в чёлку),
  перезапуск.

## Что выяснили

- Preferred Position — это запись о последнем броске приложения, а не порядок на экране.
  Сверку по нему пробовали и убрали.
- Бросок левее крайней видимой иконки, когда ряд упёрся в чёлку, иногда ложится на соседнее
  место: macOS сама решает, кого спрятать. Редактор показывает это честно. Принято, не чиним.
- Когда место в строке появляется (камера выключилась), спрятанная иконка возвращается на своё
  настоящее место, и плитка в редакторе может сдвинуться. Принято.

## Перенесено в техдолг (спринт 09)

- Бросок в пустую панель при широком разделителе (левый край может быть за экраном).
- Временный замер строки (CG / AX / Preferred Position) в отладочном логе — убрать.

## Критерий готовности

- Бросок плитки в любой ряд — иконка встаёт за ≈ 100 мс, курсор не виден, двигается одна. ✅
- Иконка под чёлкой переносится так же. ✅
- Ручной Cmd+drag и новая иконка видны в редакторе после ближайшей сверки. ✅
- После перезапуска Nook ряды те же. ✅
- Кода «Применить» в проекте нет. ✅
