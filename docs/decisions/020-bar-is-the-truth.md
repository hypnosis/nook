# 020 — Правда — строка меню: порядок читается из строки, иконки переносятся по одной

> **История.** Раскладку описывает ADR 022 «Логика раскладки». Где этот документ с ним расходится, прав 022.

> Принято 2026-10-04, реализовано в 0.4.0–0.4.1 (спринт 10). Заменяет модель «реестр задумал —
> „Применить“ догоняет» из ADR 013. Способ переноса из ADR 019 остаётся.

## Context

Nook хранил порядок иконок как «должно быть» и по кнопке «Применить» догонял им строку меню.
Почти все баги были расхождениями этих двух правд. Каждая заплатка (добивочные проходы,
выталкивание в чёлку, пересоздание разделителя, сверка «всё ли встало») добавляла новый случай.

Адресный перенос (ADR 019) двигает любую иконку за 70–90 мс, в том числе спрятанную под
чёлкой. Значит, догонять не нужно: каждый бросок можно сразу сделать в строке.

## Decision

1. **Правда — строка меню.** Nook сверяет своё состояние со строкой, а не наоборот. Ручной
   Cmd+drag, новая или пропавшая иконка — обычные события, их ловит сверка.
2. **Один список:** `[панель …] разделитель [основной ряд …]`. Ряд иконки — сторона разделителя.
3. **Один бросок — один перенос** к соседу по редактору; между рядами сосед — разделитель.
   Внутри панели бросок строку не трогает, меняется только порядок панели.
4. **После переноса реестр перечитывается из строки**, а редактор показывает, куда иконка
   встала на самом деле. Проверки «встала» и отката плитки нет.
5. **Nook без действия пользователя ничего не двигает.**

### Сверка со строкой

- **Основной ряд — порядок строки целиком**, вместе с иконками, которые macOS не нарисовала.
  В координатах окон спрятанные иконки всегда крайние слева, поэтому видимая строка — правый
  хвост ряда в редакторе.
- **Панель держит свой порядок.** Иконки панели спрятаны за разделителем, их порядок в строке
  пользователю не важен. Новая иконка встаёт за соседом слева по строке, пропавшая уходит.
- **Пока открыт раздел «Расположение», разделитель не сужается** (ADR 016 — только при клике по
  копии в панели): иначе строка перестраивается посреди бросков.
- Строка свёрнута или разделитель узкий — сверка пропускается до следующего раза.

### Порядок панели на диске

Порядок панели хранится в настройках Nook (`panelOrder`) списком имён приложений, как их
показывает macOS: «Ollama», «CleanShot X». При старте он применяется, как только известны
приложения всех иконок панели (через Accessibility), дальше каждое изменение записывается.

### Бросок у чёлки

Если точка отпускания попадает под чёлку, иконка отпускается сразу правее её края. Если и
сосед под чёлкой — на самом соседе.

### Неподвижная иконка

Иконка, которая не принимает перенос (Little Snitch), до перезапуска Nook больше не
переносится: попытка стоит ≈ 1 с.

## Что выяснили (пробы 2026-10-04, Tahoe, MacBook с чёлкой)

| Что | Результат |
|---|---|
| Адресный перенос, в том числе под чёлку | ≈ 70–110 мс на бросок |
| Камера включена, основной ряд упёрся в чёлку | macOS не рисует часть иконок; в координатах они крайние слева |
| Свёрнутая строка | Порядок окон совпадает с Preferred Position |
| Раскрытая строка с переполнением | Спрятанные окна сдвинуты влево, даже если на деле стоят между видимыми |
| Preferred Position после броска | Обновляется через 150–300 мс, но это запись о броске, а не порядок на экране |
| Бросок левее крайней видимой иконки при переполнении | Иногда ложится на соседнее место: кого спрятать, решает macOS |

## Consequences

- Бросок — ≈ 100 мс вместо ≈ 700 мс у «Применить», курсор не виден.
- Редактор всегда совпадает с видимой строкой.
- Когда место появляется (камера выключилась), спрятанная иконка возвращается на своё
  настоящее место, и плитка в редакторе может сдвинуться. Принято.
- Бросок в слот у чёлки иногда отскакивает на соседнее место. Принято, редактор показывает честно.
- Приложение, не запущенное при старте Nook, теряет место в сохранённом порядке панели.
- Код «Применить» удалён целиком.

## Alternatives

- **Чинить реестр и «Применить» дальше.** Каждая починка открывала новый случай. Отвергнуто.
- **Сверка по Preferred Position.** Пробовали: это запись последнего броска, а не порядок
  на экране, и у части иконок запись берётся не у того приложения. Отвергнуто.
- **Спрятанные иконки держат место по реестру.** Редактор расходился с видимой строкой при
  переполнении. Отвергнуто.
- **Сохранять порядок по bundle id.** Имена приложений читаются в файле настроек. Выбраны имена.
