# 019 — Перенос иконок адресными событиями, как у Ice на Tahoe

> Принято 2026-10-04. Уточняет ADR 013: меняется способ переноса и ожидание между переносами.
> **Действует раздел «Как переносим» и «Курсор»:** так делается каждый бросок в редакторе
> (ADR 020). Разделы про «Применить» — история: кнопки больше нет.

## Context

«Применить» стало медленным и заметным: курсор было видно, иконки тянулись по строке, весь
прогон занимал 4–6 с. Порядок вставал не с первого раза, а после неудачного прогона в строке
появлялись дубли. Мы разобрали, как переставляет иконки Ice в ветке для macOS 26. Вывод
исследования: переставить чужие иконки без событий мыши на Tahoe нельзя, но вести курсор по
строке не обязательно.

## Decision

### Как переносим

- **Нажатие и отпускание, без перетаскивания.** Иконке шлётся нажатие с Cmd и сразу
  отпускание. Обе точки — у края соседа: при переносе влево — его левый край, при переносе
  вправо — его правый край минус ширина иконки.
- **События адресованы окнам.** В событии указаны окно иконки и окно соседа, а также процесс
  настоящего владельца иконки (его находим через Accessibility заранее, пока иконки видны).
  Событие идёт и в общий поток, и прямо процессу.
- **Перетаскивание по координатам — запасной путь.** Если иконка не ответила за 150 мс,
  пробуются прежние способы Cmd+drag из ADR 013.

### Курсор

Nook — фоновое приложение, и прятать курсор macOS ему не даёт. Перед первым переносом Nook
включает себе приватное свойство соединения `SetsCursorInBackground`, после этого курсор
действительно исчезает на время «Применить».

### Ожидание между переносами

После адресного переноса строка не ждёт тишины: следующий перенос идёт через 25 мс. Ждать
устоявшихся координат нужно только перетаскиванию. Конец переноса проверяется по порядку
окон, а не по их x: иконки с живой шириной (Stats) не мешают.

### Что ещё изменилось в «Применить»

- **Разделитель не таскаем.** Он ставится отдельно, переносы его не трогают.
- **Разделитель не пересоздаётся, если стоит на месте:** левее первой иконки основного ряда
  и без чужих иконок между ними.
- **Индикатор записи экрана — не иконка.** Окно системного индикатора (`AudioVideoModule`)
  исключено из списка иконок: раньше разделитель вставал перед ним, и панель оставалась
  видна.
- **Иконки панели не переставляем между собой.** Панель рисует их по своему порядку, в строке
  им нужно только стоять левее разделителя.
- **Выталкивание в чёлку — только по нужде:** когда иконка основного ряда не поместилась.
- **Честная проверка.** «Не всё встало» показывается, если основной ряд стоит не по порядку
  или иконка оказалась не по ту сторону разделителя.
- **Сразу после «Применить»** редактор и открытая панель переснимаются, не ждут тика.
- **Неудачный снимок не ломает редактор.** Иконка, которую ScreenCaptureKit не снял, остаётся
  в редакторе с прежней картинкой. Раньше она пропадала, и следующее «Применить» уводило
  основной ряд в панель.

## Что выяснили (замеры на Tahoe, MacBook с чёлкой)

| Что | Результат |
|-----|-----------|
| Адресный перенос одной иконки | ≈ 50–75 мс |
| «Применить» без переносов | ≈ 155 мс |
| «Применить» с одним–тремя переносами | ≈ 340–830 мс |
| Прежний прогон с перетаскиванием и ожиданием тишины | 4–6 с, курсор виден |
| Выталкивание в чёлку без нужды | ≈ 3 с впустую |
| Адресный перенос с точкой далеко за краем и без процесса владельца | Не работает |
| Снимок ScreenCaptureKit при движении мыши | Иногда «неполадки при захвате аудио/видео» на большинство окон |

## Consequences

- «Применить» занимает доли секунды, курсор не виден, мышь не уезжает.
- Опора на два приватных механизма: поле события с номером окна и `SetsCursorInBackground`.
  Их нужно проверять после каждого обновления macOS. Если адресный перенос сломается, Nook
  сам уйдёт на перетаскивание — медленнее, но работает.
- Владельцев иконок нужно знать до переноса. Спрятанные иконки через Accessibility не найти,
  поэтому владельцы ищутся заранее, когда открыт редактор.
- Порядок иконок панели в строке меню больше не совпадает с порядком в панели. Это нормально:
  в строке они спрятаны.

## Alternatives

- **Оставить перетаскивание и ускорить ожидание.** Курсор всё равно виден, а ошибка
  координат накапливается с каждым переносом. Отвергнуто.
- **Переставлять без событий мыши** (Accessibility, defaults, приватные API строки меню).
  На Tahoe не работает: чужие иконки принадлежат ControlCenter. Отвергнуто.
- **Танец Ice с временной подменой событий** (перехват своих же событий, двойное отпускание).
  Без него адресный перенос уже работает. Отложено, пока не понадобится.
