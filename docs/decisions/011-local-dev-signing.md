# 011 — Локальные сборки подписаны ad-hoc, как релиз

## Context

Панели нужны два права macOS: запись экрана (снимки иконок под чёлкой) и Accessibility (нажатие настоящей иконки). При ad-hoc подписи права привязаны к хэшу конкретной сборки и слетают при каждой пересборке. Developer ID на машине нет.

## Decision

Локальная установка подписывается так же, как релиз: ad-hoc в `bundle.sh` / `make-dmg.sh`. Скрипт `scripts/install-local.sh` только собирает Nook через `bundle.sh` и ставит его в `/Applications` (путь важен, см. ADR 008). Своих сертификатов подписи нет.

## Consequences

- Локальная установка ведёт себя как сборка из DMG: онбординг и выдача прав проверяются в тех же условиях, что у пользователя.
- После пересборки права слетают. В Системных настройках может остаться прежняя запись Nook с включённым тумблером, которая уже не действует: её выключают и включают заново или удаляют и выдают право снова.
- Права, переживающие обновление, появятся с Developer ID (спринт 07).

## Alternatives

- **Самоподписанный сертификат.** Права переживают пересборку, но локальная сборка перестаёт быть похожей на релиз — отвергнуто.
- **Developer ID.** Правильный путь, но аккаунта разработчика пока нет — переход в спринте 07.
