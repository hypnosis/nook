# 011 — Временная локальная подпись «Nook Local Dev»

> Принято 2026-10-01. Временное решение, убрать в спринте 07.

## Context

Панели нужны два права macOS: запись экрана (снимки иконок под чёлкой) и Accessibility (нажатие настоящей иконки). При подписи ad-hoc права привязаны к хэшу конкретной сборки: после каждой пересборки они слетают, их приходится сбрасывать и выдавать заново. Developer ID на машине нет.

## Decision

На этом Mac создан самоподписанный сертификат подписи кода «Nook Local Dev» (в связке ключей входа, использовать разрешено только `codesign`). Скрипт `scripts/install-local.sh` собирает Nook через `bundle.sh`, переподписывает этим сертификатом и ставит в `/Applications`. Требование подписи становится «идентификатор `com.hypnosis.nook` + этот сертификат» и не меняется между сборками, поэтому выданные права сохраняются.

`bundle.sh`, `make-dmg.sh` и релизная подпись не меняются: это только для локальной разработки.

## Consequences

- Права выдаются один раз и переживают пересборки.
- Сертификат живёт только на этой машине; на другой Mac сборка с ним не ставится как доверенная.
- Это хардкод: скрипт помечен `HARDCODE`, удаление расписано в `sprints/planned/07_DEVOPS_remove-local-dev-cert.md`.

## Alternatives

- **Ad-hoc, как раньше.** Права слетают на каждой сборке — отвергнуто, тормозит каждый шаг проверки.
- **Developer ID.** Правильный путь, но аккаунта разработчика пока нет — переход в спринте 07.
