# 012 — Панель под строкой меню для иконок, ушедших под чёлку

> Принято 2026-10-01. Уточняет ADR 003 и 004: для этой панели мы всё-таки снимаем чужие иконки и нажимаем их через Accessibility.

## Context

На MacBook с чёлкой раскрытая строка меню не вмещает все иконки: часть уходит под чёлку, и до них не достать. Нужна панель под строкой меню, где эти иконки видны и кликаются. Механизм скрытия (спейсер, его ширина, guard, размещение — ADR 005, 007) остаётся как был, панель только добавляется.

## Decision

Клик по `<` раскрывает строку, как и раньше, и одновременно открывает панель. В панели лежат картинки-клоны иконок, которые не поместились. Клик по клону нажимает настоящую иконку, и открывается её родное меню. Одна иконка никогда не видна в двух местах: в панель попадают только те, что macOS сама не нарисовала.

Как устроено:

- **Какие иконки брать.** Окна иконок строки меню принадлежат ControlCenter (слой 25, верх экрана, высота не больше 50 pt). Не поместившиеся стоят на экране (x ≥ 0), но помечены как не нарисованные. Их и берём, слева направо.
- **Картинка.** ScreenCaptureKit снимает каждое окно отдельным фильтром.
- **Клик.** Accessibility: у приложения-владельца ищем его иконку в строке меню и выполняем «нажать» (AXPress). Иконку сопоставляем с окном по центру по горизонтали.
- **Кэш.** Снимки живут в панели и между открытиями не пропадают. Найденные кнопки Accessibility лежат в памяти, пока работает Nook.
- **Старт.** Пока строка ещё раскрыта, перед стартовым авто-скрытием, за один проход снимаем иконки и ищем их кнопки. Скрываем строку, когда готовы оба шага. Поэтому уже первое открытие показывает иконки сразу, и первый клик тоже мгновенный.
- **Обновление.** Пока панель открыта, клоны переснимаются раз в 2 с. Так панель видит, что иконка сменила вид (например, VPN включили или выключили). Панель закрыта — таймеров нет.
- **Пакетность.** Один проход — один запрос списка окон. Все приложения опрашиваются в Accessibility одновременно, а не по очереди.
- **Автосворачивание** не срабатывает, пока мышь над панелью.

Нужны два права: «Запись экрана» и «Универсальный доступ». Чтобы они не слетали при каждой пересборке, локальные сборки подписаны сертификатом (ADR 011).

## Что выяснили (замеры на Tahoe, MacBook с чёлкой)

| Что | Результат |
|-----|-----------|
| Иконки, не поместившиеся в раскрытую строку | x ≥ 0, «не нарисовано». macOS прячет их одним блоком, даже те, что справа от чёлки |
| Иконки, спрятанные спейсером | x < 0. Не снимаются и не сопоставляются с Accessibility, поэтому кэш собирается только пока строка раскрыта |
| `CGWindowListCopyWindowInfo` по одному окну | Для таких окон возвращает пусто. Работает только поиск по полному списку |
| ScreenCaptureKit, несколько окон в одном фильтре | Ошибка −3811. Нужен один фильтр на окно |
| ScreenCaptureKit, скорость | Список окон ≈ 30 мс, снимок 3 иконок ≈ 60–90 мс |
| Клик мышью (CGEvent) по координатам иконки под чёлкой | Не работает, и отправка событий прямо процессу ControlCenter тоже |
| AXPress на иконке приложения | Работает. Центры элемента Accessibility и окна совпадают с точностью до 1 pt (берём допуск 6 pt) |
| Время ответа AXPress | AdGuard, Time Machine: 0–26 мс. cmux, CleanShot: меню открывается, но вызов отвечает ошибкой −25204 через 1–1,5 с |
| Поиск кнопок Accessibility по приложениям по очереди | ≈ 0,5–0,55 с |
| То же, все приложения одновременно | ≈ 0,12 с |
| Клик с найденной заранее кнопкой | 0 мс на поиск |
| Первое открытие без стартового снимка | Панель пустая ≈ 0,45 с (0,34 с — пауза перед снимком) |
| Стартовый снимок и поиск кнопок | Авто-скрытие при запуске сдвигается на ≈ 0,15 с |
| Права с ad-hoc подписью | Привязаны к хэшу сборки и слетают при пересборке (решено в ADR 011) |

## Consequences

- Иконки из-под чёлки снова доступны: панель открывается сразу с картинками, клики мгновенные.
- Это та самая «хрупкая» зона, от которой предостерегали ADR 003/004: снимки чужих окон и Accessibility. Если macOS поменяет устройство строки меню, сломается именно панель. Скрытие спейсером от неё не зависит.
- Пока панель открыта, раз в 2 с идёт пересъёмка: немного работы, но только в это время.
- Приложение, запущенное после старта Nook, появится в панели примерно через 0,3–0,5 с после первого открытия, а не мгновенно.

## Alternatives

- **Свои ярлыки вместо снимков (полу-IceBar, ADR 004).** Не показывают живой статус иконки (VPN вкл/выкл), отвергнуто для этой панели.
- **Клик мышью по координатам.** Не доходит до иконки под чёлкой, отвергнуто по замеру.
- **Снимать только при открытии, без кэша на старте.** Первое открытие пустое ≈ 0,45 с, отвергнуто.
- **Искать кнопки Accessibility после скрытия.** Иконки уже за краем, сопоставление 0 из 3, отвергнуто.
