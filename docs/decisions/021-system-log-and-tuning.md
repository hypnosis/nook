# 021 — Лог в системный журнал, настроечные числа в одном месте

> Принято 2026-10-04.

## Context

Лог писался в `/tmp/nook-debug.log` и включался флагом сборки `debug-log`: чтобы посмотреть,
что делает Nook, его нужно было пересобрать. Файл открывался на каждую строку, строка
собиралась даже при выключенном логе, уровней не было — сбой и координата броска выглядели
одинаково. Настроечные числа (паузы, ширины, допуски) были раскиданы по модулям, одинаковые
значения заведены в нескольких местах.

## Decision

**Лог — системный журнал macOS** через фасад `log` и крейт `oslog`. Подсистема — bundle id,
категория — модуль (`nook::mover`, `nook::controller`).

| Макрос | В журнале | Что пишем | Когда пишется |
|--------|-----------|-----------|---------------|
| `warn!` | Error | сбои: нет права, перенос завис, снимок не вышел | всегда |
| `info!` | Default | ключевые события: перенос, записан порядок, пересоздан айтем | всегда |
| `debug!` | Info | подробности: координаты, тайминги, порядок рядов | только с флагом |

Флаг подробностей — ключ `debugLog` в настройках Nook, без пересборки:

```
defaults write com.hypnosis.nook debugLog -bool YES   # включить, нужен перезапуск Nook
defaults delete com.hypnosis.nook debugLog            # выключить
log stream --level info --predicate 'subsystem == "com.hypnosis.nook"'
log show --last 10m --info --predicate 'subsystem == "com.hypnosis.nook"'
```

**Настроечные числа — `src/tuning.rs`.** Геометрия строки меню, паузы, таймауты, допуски.
Ключи настроек, имена символов и размеры окон остаются рядом со своим кодом.

## Consequences

- Обычный Nook молчит: подробности не собираются, система сама хранит и чистит журнал.
- Включить подробный лог можно на любой сборке, в том числе релизной.
- Уровни `oslog` сдвинуты на ступень относительно имён макросов — таблица выше.
- В zsh `log` — встроенная команда: из Терминала звать `/usr/bin/log`.

## Alternatives

- **Свой файл с уровнями и флагом.** Ротацию, время, фильтры пришлось бы писать самим. Отвергнуто.
- **`tracing` + `tracing-oslog`.** Больше зависимостей ради того же результата. Отвергнуто.
