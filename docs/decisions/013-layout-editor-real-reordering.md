# 013 — Редактор раскладки: Nook сам переставляет настоящие иконки

> Принято 2026-10-02. Продолжает ADR 012: пробы оттуда превращены в редактор.

## Context

Пользователь хочет сам решать, какие иконки видны в строке меню, а какие живут только в панели под ней. Руками это делается через Cmd+drag, долго и неудобно. Нужен редактор, где иконки раскладываются по двум рядам, а Nook потом сам переставляет настоящие иконки так, как нарисовано. Пробы в ADR 012 показали, что это возможно: поддельный Cmd+drag двигает иконки, а второй невидимый разделитель прячет иконки панели внутри экрана, где панель их видит.

## Decision

В настройках есть раздел «Расположение» с двумя рядами: «Основной ряд» и «Панель». Иконки перетаскиваются между рядами, кнопка «Применить» переставляет настоящие иконки. Раскладка в строке меню:

```
[панель] [разделитель 2] [основной ряд] [≡◂] [<] [остальное]
```

### Ширина разделителя 2

Разделитель 2 должен спрятать иконки панели внутри экрана: не уйти за левый край (тогда их не снять) и не попасть в опасную зону 300–400 pt (ADR 012). Ширина считается по реальным позициям:

```
ширина = x первой иконки основного ряда − 16 (рамка окна) − сумма ширин иконок панели − 20 (отступ от края)
```

Но не меньше 500 pt. Ставится одним шагом. Перед замером ждём, пока строка меню доиграет анимацию: иначе позиции устаревшие, разделитель выходит шире, и крайняя иконка панели уезжает за край.

### Как переставлять иконки

- **Минимум переносов.** Самая длинная цепочка иконок, которые уже стоят в нужном порядке друг относительно друга, остаётся на месте. Двигаются только остальные.
- **Свежие координаты.** macOS анимирует перестройку строки меню после каждого переноса. Следующий перенос ждёт, пока строка успокоится: два замера подряд через 10 мс без изменений. Только потом берутся координаты.
- **Куда бросать.** Иконка, которая едет влево, бросается на левый край соседа справа. Та, что едет вправо, — на правый край соседа слева. Так она встаёт ровно между соседями.
- **Добивочный проход.** Если после всех переносов порядок не совпал, план пересчитывается по свежим позициям и выполняется ещё раз, но не больше одного раза.
- **Мышь.** На время переноса курсор спрятан, физическая мышь отвязана от него. Сторож через 5 с возвращает мышь в любом случае.

### Неподвижные иконки

Некоторые приложения не принимают поддельные события мыши: руками Cmd+drag работает, программно нет. Пример — Little Snitch, скорее всего из-за защиты от поддельных кликов. Обходить эту защиту не стали. Вместо этого неподвижная иконка остаётся на месте, а остальные иконки и наш разделитель ставятся вокруг неё.

Иконка считается неподвижной, только когда выполнены все три условия:

1. Перенос действительно нужен: иконка не стоит уже между нужными соседями.
2. Ни один из трёх способов переноса её не сдвинул, положение проверено через систему.
3. В том же «Применить» другая иконка сдвинулась успешно. Значит, перенос в целом работает, и дело именно в этой иконке.

После этого план пересчитывается: неподвижная иконка получает огромный вес и всегда попадает в цепочку «стоят на месте». Пометка живёт до перезапуска Nook, потому что номер окна иконки меняется при перезапуске приложения.

## Что выяснили (замеры на Tahoe, MacBook с чёлкой)

| Что | Результат |
|-----|-----------|
| Один перенос без ожидания анимации | ≈ 50 мс |
| То же с ожиданием, пока строка успокоится | ≈ 150 мс, из них ожидание ≈ 75 мс |
| Переносы подряд без ожидания анимации | Иконки встают не туда: промах ровно на ширину предыдущей иконки |
| Подсказка «x окна сдвинулся на 1 pt» | Значит, что анимация началась, а не закончилась. Не годится как знак «перенос завершён» |
| Ширина разделителя, посчитанная сразу после переносов | Ошибка ≈ 30 pt, крайняя иконка панели ушла за край |
| Little Snitch: быстрый способ, через середину, с паузами | Не сдвигается |
| Little Snitch: удержание кнопки 300 мс, переход за 6 шагов | Не сдвигается |
| Little Snitch: нажатие самой клавиши Cmd вместе с событием | Не сдвигается |
| Little Snitch: курсор наводится заранее, пауза перед нажатием | Не сдвигается |
| Little Snitch: руками Cmd+drag | Сдвигается |
| Попытка сдвинуть неподвижную иконку | ≈ 1 с впустую — поэтому пометка запоминается |
| Перенос «вокруг» Little Snitch в панель | 3 переноса по ≈ 50 мс, порядок верный |

## Consequences

- Раскладку можно собрать мышкой в окне настроек, без ручного Cmd+drag в строке меню.
- Иконки, которые не принимают поддельные события, тоже попадают куда нужно, только за счёт переноса соседей. Ограничение: две такие иконки нельзя поменять местами между собой.
- Ожидание анимации стоит ≈ 75–100 мс на перенос. Если станет медленно, следующий шаг — предсказывать позиции, а не ждать.
- После перезапуска Nook первое «Применить» с неподвижной иконкой длится на ≈ 1 с дольше: пометка выясняется заново.
- Если перенос не удался, пользователь пока этого не видит: редактор молча показывает настоящий порядок. Нужна подсказка.

## Alternatives

- **Подделать источник события под настоящую мышь, чтобы Little Snitch его принял.** Это обход механизма безопасности, и он может перестать работать в любой версии. Отвергнуто.
- **Пометить такие иконки «не переносится» и не давать их таскать.** Теряется контроль, хотя расставить их можно и без переноса. Отвергнуто.
- **Длинные паузы во всех переносах.** Медленно и не лечит промахи: координаты всё равно устаревшие. Отвергнуто.
- **Предсказывать позиции без ожидания анимации.** Быстрее, но сложнее, и при ошибке модели нужен добивочный проход. Отложено.
- **Ставить разделитель 2 фиксированной ширины.** Безопасная ширина зависит от числа иконок в панели и ширины экрана. Отвергнуто.
