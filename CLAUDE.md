# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Nook — лёгкая нативная утилита для macOS, которая прячет лишние иконки строки меню. Свёрнутая
строка прячет всё левее `<`; раскрытая показывает основной ряд, а иконки панели — только в
панели под строкой меню, снимками, которые нажимают настоящую иконку.

> **Поведение раскладки (панель, разделитель, авторежим, редактор) описывает только ADR 022
> «Логика раскладки». Он приоритетнее остальных ADR и кода.** Любая правка раскладки
> проверяется по его сценариям 1–9; ADR 012, 013, 015, 016, 018, 020 — история.

## Зафиксированные технические решения

- **Стек: Rust + objc2.** objc2 — тонкая обёртка над нативным AppKit (`NSStatusItem`,
  `NSStatusBar`): строкой меню в macOS можно управлять только через родные API Apple. Swift и
  Tauri отвергнуты (ADR 001).
- **Таргет: macOS 26 Tahoe.**
- **Свои элементы строки:** якорь `<`, общий разделитель (спейсер, прячет всё при сворачивании)
  и разделитель панели. Nook никогда не переносит свои элементы событиями мыши: событие в
  собственный процесс показывает спрятанный курсор.
- **Панель:** снимки иконок через ScreenCaptureKit (право «Запись экрана»), нажатие через
  Accessibility (AXPress), перенос иконок адресными событиями мыши с Cmd, как у Ice (ADR 019).
- **Источники истины:** строка меню — какие иконки есть и по какую сторону разделителя панели;
  диск (`panelOrder`) — порядок панели. Панель и редактор — только вид модели (`layout.rs`).

## Команды

- `cargo build` — сборка, `cargo test` — автотесты сценариев раскладки, `cargo clippy` — линтер.
- `scripts/install-local.sh` — собрать, подписать, поставить в `/Applications` и запустить.
- Подробный лог: `defaults write com.hypnosis.nook debugLog -bool YES`, затем перезапуск;
  читать `/usr/bin/log show --info --debug --predicate 'subsystem == "com.hypnosis.nook"'`.
