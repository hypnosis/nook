# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Nook — лёгкая нативная утилита для macOS, которая прячет лишние иконки строки меню. Свёрнутая
строка прячет всё левее `<`; раскрытая показывает основной ряд, а иконки панели — только в
панели под строкой меню, снимками, которые нажимают настоящую иконку. В строке иконки панели
стоят у чёлки под шторкой, поэтому их меню открывается у чёлки.

> **Поведение раскладки (панель, разделитель, авторежим, редактор) описывает только ADR 022
> «Логика раскладки». Он приоритетнее остальных ADR и кода.** Любая правка раскладки
> проверяется по его сценариям 1–9; ADR 012, 013, 015, 016, 018, 020 — история.
> Перед правкой шторки, разделителя, нажатия или сторожа читать его раздел «Правила шторки,
> длины и сторожа».

## Зафиксированные технические решения

- **Стек: Rust + objc2.** objc2 — тонкая обёртка над нативным AppKit (`NSStatusItem`,
  `NSStatusBar`): строкой меню в macOS можно управлять только через родные API Apple. Swift и
  Tauri отвергнуты (ADR 001).
- **Таргет: macOS 26 Tahoe.**
- **Свои элементы строки:** якорь `<`, общий разделитель (спейсер, прячет всё при сворачивании)
  и разделитель панели. Nook никогда не переносит свои элементы событиями мыши: событие в
  собственный процесс показывает спрятанный курсор.
- **Панель:** снимки иконок через ScreenCaptureKit (право «Запись экрана»), нажатие через
  Accessibility (AXPress), перенос иконок адресными событиями мыши с Cmd, как у Ice (ADR 019).
- **Шторка:** окно над строкой со снимком пустой полосы, ловит клики; разделитель панели 12 pt
  под ней или 500 pt, других длин macOS не держит (ADR 022).
- **Источники истины:** редактор — намерение, строка — факт. Диск (`panelOrder`) хранит
  намерение: какие иконки в панели и в каком порядке. Строка меню — какие иконки есть и где
  стоят. Nook приводит факт к намерению; своя осечка переноса намерение не меняет. Панель и
  редактор — только вид модели (`layout.rs`).

## Команды

- `cargo build` — сборка, `cargo test` — автотесты сценариев раскладки, `cargo clippy` — линтер.
- `scripts/install-local.sh` — собрать, подписать, поставить в `/Applications` и запустить.
- Лог пишется только в режиме отладки: `defaults write com.hypnosis.nook debugLog -bool YES`, затем перезапуск;
  читать `/usr/bin/log show --info --debug --predicate 'subsystem == "com.hypnosis.nook"'`.

## Где что лежит

- `src/controller/` — контроллер по частям: старт, сворачивание, чтение строки, шторка,
  переносы, сторож порядка, меню и настройки.
- `src/bar.rs` — чтение строки меню, `src/layout.rs` — модель раскладки и автотесты сценариев,
  `src/mover.rs` — перенос иконок.
- `docs/decisions/` — зафиксированные технические решения (ADR), почему выбран тот или иной путь.
- `docs/project/OVERVIEW.md` — что это и зачем, простым языком.
- `sprints/planned/` — план работ по MVP, разбитый по функционалу.
- `sprints/roadmap/ROADMAP.md` — фазы проекта.
